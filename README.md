# CuentaClara

Diseño de interacción para una aplicación móvil que ayuda a repartir gastos grupales a partir de una boleta. Sumativa 2 de Interacción Humano Computador.

## Decisiones documentadas

- **Asignación por ítem.** Entre las dos alternativas del informe se eligió recorrer la boleta una vez y seleccionar a las personas en cada fila. En partes iguales, el flujo pasa directamente al resumen.
- **Control de errores.** Se puede reintentar la foto o corregir la lectura. Los ítems pendientes se asignan manualmente o se reparten entre todos mediante una acción explícita.
- **Propina opcional.** El resumen parte sin propina y ofrece 10% como opción sugerida. Se muestran por separado el consumo, la propina y el total.

## Caso ilustrado

La boleta suma $22.000. Camila y Diego tienen un consumo individual de $8.000 y comparten unas papas de $6.000. Cada persona queda con $11.000 de consumo y, al seleccionar el 10%, suma $1.100 de propina. El total final es $24.200. Los datos son ficticios.

Los wireframes representan el comportamiento previsto y pueden revisarse en el orden indicado. El historial de commits registra la incorporación de la documentación y los entregables.
